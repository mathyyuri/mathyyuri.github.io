오답노트 생성기 (베타)

사용 순서

  1. 아래에서 교재 목록의 파일을 불러오거나(여러 개 가능), 내 컴퓨터에서 직접 업로드
  2. 불러온 시험지마다 감지된 문제 번호가 체크박스로 나타남 — 틀린 문제를 체크 (여러 시험지 섞어서 체크 가능, 시험지별 "전체 선택" 버튼 있음)
  3. 개별 학생용은 학생 이름을 입력 후 생성, 수업용(전체 학생 공용)은 이름 없이 바로 한글파일 또는 HTML로 생성

문제 번호는 자동으로 감지됩니다: [[N]] 수동 표시, 미주(각주) 번호, 또는 "1. " 처럼 이미 매겨진 번호 — 셋 다 있으면 합쳐서 인식합니다. 체크박스에 마우스를 올리면 해당 문제의 미리보기 텍스트가 뜹니다.
