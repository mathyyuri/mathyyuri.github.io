오답노트 생성기 (베타)

사용 순서

  1. 선생님이 만든 원본 시험지 한글 파일을 .hwpx로 저장 (한글에서 "다른 이름으로 저장" → 파일 형식 "한글 표준 문서(*.hwpx)")
  2. 아래에서 그 파일을 업로드하면, 문제 번호를 자동으로 감지합니다 (아래 3가지 방식 중 하나가 이미 되어있으면 따로 손댈 필요 없음)
  3. 학생 이름과 틀린 문제 번호를 입력한 뒤 생성

문제 번호 인식 방식 (위에서부터 우선순위로 시도):

  1. 수동 표시: 문제 앞에 [[1]], [[2]]... 만 적힌 문단을 넣고 맨 끝에 [[END]]
  2. 미주 번호: 문제마다 해설을 미주(각주)로 순서대로 달아둔 경우, 그 미주 번호를 문제 번호로 자동 인식
  3. 자동 번호 인식: 문제 문단이 이미 "1. ", "2. " 처럼 시작하면 그 번호를 자동 인식 (증가하는 순서일 때만)
